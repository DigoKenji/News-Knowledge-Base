**2. sqlite3_rsync: Database Remote-Copy Tool For SQLite** — Blog · data
Offers a way to snapshot and sync SQLite databases without duplicating disk space or resending everything.
- sqlite3_rsync streams a database snapshot over SSH without first creating a full local copy.
- It syncs an existing copy by exchanging page hashes and transferring only the pages that differ, like rsync.
- When copies start out vastly different, hash overhead can exceed database size, though the excess is a few percent at most.
