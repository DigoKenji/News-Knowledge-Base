**1. À procura da HRO, a organização muito confiável (em que pesem os paradoxos)** — Blog · architecture
Shows how well-meant AI oversight rules can weaken the human judgment that keeps high-risk operations safe.

**2. OpenAI and Cisco introduce Shirudo** — Blog · security
Shows a way to shield running Linux services from exploits while patches are still pending, using eBPF and signed rules.
- Shirudo uses eBPF shields to block exploit code paths in running Linux systems without restarts.
- Shields can be monitored before enforcement, are signed and verified before loading, and recorded with TPM-backed evidence.
- A Codex-generated input check blocked a Java4Shell exploit against a running Elasticsearch process in a controlled test.
[Deep dive](https://app.notion.com/p/426baf74172d810386bcd52eaae20e4a) · [Original](https://openai.com/index/introducing-shirudo)

**3. Model Weights, Airlocks and Sandboxes: A Call for Technical Validation of Re-identification Tests under the EDPB Anonymisation Guidelines** — arXiv · security
Any model-release or output gate needs a test whose reliability is known; a passing result alone proves little.
- Releasing weights, query access or airlock outputs needs evidence of anonymity, and failed attacks prove little.
- Test methods should be validated as measurement methods, with stated detection limit, bias and uncertainty.
- Evidence is formal, empirical (attack tests) or indirect; only formal bounds hold against any attacker.
[Deep dive](https://app.notion.com/p/426baf74172d81028cd2ec0e7513337b) · [Original](https://arxiv.org/abs/2611.34859)

**4. Ontologies, Knowledge Graphs, and a Semantic Layer: The Architecture That Makes AI Stop Guessing** — Medium · architecture
Explains why RAG-style grounding alone cannot make AI answers correct in structured domains, and the layered fix.
- An ontology defines what things mean, legal relationships and constraints, separate from the facts stored in a graph.
- A knowledge graph holds current verified facts, and a semantic orchestration layer validates them before the LLM generates.
- Linguistic frames fix verbalization at design time, so the LLM only fills grammar, not interpretation.
[Deep dive](https://app.notion.com/p/426baf74172d81e6a13bc9f44c0bca17) · [Original](https://medium.com/@vimal-dwarampudi/your-ai-is-guessing-heres-how-to-make-it-stop-e1874bfa312a)

**5. OKF + RAG: The Ultimate AI Agent Architecture** — Medium · ai-ml
Shows how to split agent knowledge between authoritative Git-versioned facts and probabilistic retrieval, a common enterprise problem.
- RAG retrieves similar text, not authoritative text, so exact facts like formulas need a curated source.
- OKF stores curated knowledge as Git-versioned Markdown files with YAML frontmatter, one concept per file, with no vector infrastructure.
- A router tries the OKF store first and falls back to vector RAG search when nothing matches.
[Deep dive](https://app.notion.com/p/426baf74172d81dda71dfd3a5709695a) · [Original](https://medium.com/@ravishkhullar/okf-rag-the-ultimate-ai-agent-architecture-26b9ceed44f1)
